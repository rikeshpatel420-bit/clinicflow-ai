# BuildFlow Profile

BuildFlow is the construction and contractor vertical on Flow Platform.

## Purpose

- Capture quotes
- Qualify projects
- Route urgent site issues
- Collect survey and callback details

## Tone

- Warm
- Practical
- Calm
- British
- Professional

## Core workflows

- New build quote
- Extension quote
- Renovation work
- Structural concern
- Roof repair
- Planned works
- Handover issue
- Budget question

## Shared pattern

BuildFlow uses the shared profile builder for:

- contact entities
- message templates
- summary templates
- knowledge base defaults
- workflow scaffolding
