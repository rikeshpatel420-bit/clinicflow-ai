# Prompt Studio

Prompt Studio is the configuration layer for the AI receptionist voice and copy.

## What it controls

- greeting
- voice personality
- AI prompt
- tone
- language
- speech rate
- SSML support
- follow-up questions
- escalation phrasing

## Behaviour

Prompt Studio should produce:

- warm, concise speech
- clear handoffs to human staff
- safe emergency language
- consistent responses across voice and SMS

## What it must not do

- invent clinical advice
- give unsafe guarantees
- expose internal implementation details

## Where it is used

- onboarding
- voice calls
- message drafting
- summary generation
- workflow output
