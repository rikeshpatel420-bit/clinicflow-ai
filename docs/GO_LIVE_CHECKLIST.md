# Go Live Checklist

Use this checklist before switching a new business to live traffic.

## Required items

- Business profile completed
- Opening hours configured
- Branches and phone numbers added
- AI greeting and tone reviewed
- Knowledge uploaded
- Emergency escalation rules configured
- Users invited
- Notifications enabled
- Telephony connected
- Calendar connected
- Readiness score reviewed

## Recommended checks

- Run an emergency call test
- Run a booking test
- Run a cancellation test
- Review SMS reply handling
- Confirm staff know where to find the inbox

## Launch rule

Do not go live until the readiness engine clearly shows what is still missing.
