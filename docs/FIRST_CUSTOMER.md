# First Customer Experience

Flow OS is now organised around what a real buyer needs on day one.

## What a customer can do

- Sign up
- Create a workspace
- Configure the business
- Connect telephony and calendar tools
- Set opening hours and emergency rules
- Invite staff
- Test the AI receptionist
- Review go-live readiness
- Launch with live traffic

## Core surfaces

- `/dashboard` for business health and live activity
- `/settings` for business, branding, integrations, users, billing, and security
- `/ai` for receptionist testing and summary review
- `/workflows` for workflow simulation and approvals
- `/knowledge` for uploaded policies, pricing, and FAQs
- `/system` for readiness checks and missing setup items

## Success criteria

A first customer should know:

- what is already configured
- what still needs attention
- what must be done before go-live
- how to test the receptionist safely
