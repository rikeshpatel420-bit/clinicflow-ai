# Branding Engine

The branding engine converts the onboarding blueprint into the visual identity used across the app.

## Responsibilities

- business name
- logo or initials
- colour palette
- surface and text colours
- brand tone
- voice personality alignment

## Generated output

The engine feeds:

- the public-facing business summary
- dashboard colours
- onboarding preview cards
- prompt studio tone
- generated profile package

## Source of truth

The branding fields live in the onboarding wizard and are reused by the generated Flow Factory package.

## Design rules

- Keep the palette calm and premium
- Prefer high-contrast text
- Keep the logo simple
- Reuse the same palette across brand, dashboard, and generated docs
