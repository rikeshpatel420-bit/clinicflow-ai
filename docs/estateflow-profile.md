# EstateFlow Profile

EstateFlow is the property and estate agency vertical on Flow Platform.

## Purpose

- Capture valuations
- Book viewings
- Route property enquiries
- Handle maintenance and tenancy follow-up

## Tone

- Warm
- Calm
- Professional
- British
- Reassuring

## Core workflows

- Valuation request
- Viewing booking
- Property enquiry
- Maintenance issue
- Tenant question
- Seller callback
- Buyer callback
- Offer follow-up

## Shared pattern

EstateFlow uses the shared profile builder for:

- contact entities
- message templates
- summary templates
- knowledge base defaults
- workflow scaffolding
