# First Customer Launch Checklist

Use this checklist before a live customer goes on the platform.

## Required

- clinic membership exists
- onboarding is complete
- Twilio voice number is connected
- voice webhook is configured
- SMS webhook is configured
- status webhook is configured
- OpenAI key is configured
- Supabase URL, anon key, and service role key are configured
- billing plan catalog is present
- product profile validates cleanly
- workflows are active
- notifications are ready

## Nice to have before launch

- fallback forwarding number
- working call summaries
- inbox follow-up queue
- activation-ready marketplace view
- documentation for operators

## Launch order

1. Complete onboarding
2. Confirm tenant isolation
3. Confirm Twilio
4. Confirm AI summaries
5. Confirm billing model
6. Review `/saas`
7. Place a live test call
8. Check the dashboard and inbox
